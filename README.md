# OMIGYM 健身器材商城

纯静态、本地运行的英文电商演示站，品牌 OMIGYM，美元价格。无需数据库、安装依赖、注册账号或配置密钥。

## 启动

安装 Node.js 20 或更新版本后，在本目录运行：

```powershell
npm start
```

浏览器访问 **http://127.0.0.1:4173/**。服务仅监听本机。按 Ctrl+C 停止。

也可双击 `start-local.cmd` 启动，再打开上述网址。如端口已被占用，可指定其他端口：

```powershell
$env:PORT = '4174'
npm start
```

`dist/` 是完整网站，可使用任意本地静态 HTTP 服务运行。网站采用 ES Modules，需要通过 HTTP 打开，不要直接双击 HTML 文件。无需编译。

## 页面与功能

- 首页：品牌主视觉、产品分类、精选商品、品牌介绍。
- 产品列表 `#/shop`：分类、关键词搜索、价格/名称排序、快捷加购。
- 产品详情 `#/product/round-dumbbells`：21 款商品各自有详情，支持规格、价格、数量、图库及参数折叠；涵盖哑铃、训练架与凳、杠铃片、壶铃与杠铃、训练配件、收纳、有氧和套装。
- 品牌故事 `#/about` 和联系页 `#/contact`；联系方式为虚构示例。
- 购物车弹层及 `#/cart`：规格合并、数量修改、删除、浏览器本地保存。
- 结算 `#/checkout`：配送表单校验、模拟运费、订单确认；无支付。
- 订单确认 `#/confirmation`：本次会话内可刷新，展示订单号和商品清单；成功后清空购物车。
- 右上角头像：悬停或点击显示登录/注册入口；`#/login` 支持邮箱或手机号，提交固定提示密码错误；`#/register` 必填邮箱和六位验证码，手机号选填，发送验证码仅模拟已发送，注册提交始终提示验证码错误，实际不发送、不保存账号信息。
- 批发业务：首页批发介绍和商品列表引导统一进入 Contact；联系页说明批发服务，咨询表单可选择 Wholesale 主题，仍只在本地模拟提交。
- 响应式布局、键盘操作、原生对话框、表单标签、空状态与未找到页面。

## 演示规则

- 所有商品、价格、评分、库存、配送时效和政策均为演示数据。
- 每笔非空订单固定运费 $7.00，不设免运费门槛。无税费或其他费用。
- 每种商品规格限 1–20 件。购物车保存在当前浏览器的 localStorage。
- 联系表单和订单**不会发出网络请求**，不发送邮件，不扣费，不安排发货。
- 配送信息只用于当前表单；完成后仅将名字、订单号、商品、时间和金额放入 sessionStorage，以显示确认页。不会保存地址、电话或邮箱。
- 同浏览器跨标签页购物车会同步。浏览器禁止存储时可在当前页面使用，刷新后可能丢失。
- 可选 WebMCP 工具 `add_equipment_to_bag` 在支持的浏览器中可用，与网页加购共用逻辑，不会提交订单。

## 后台订单页面

启动后打开 **http://127.0.0.1:4173/admin.html**。后台采用独立的深蓝/灰白/青绿设计，不影响前台。

- 2026 年 6 月 25 日至 9 月 22 日，连续 90 天共 409 笔模拟订单，每天随机 3–6 笔；固定种子保证刷新结果一致。
- 共 300 位模拟客户、109 笔复购，复购间隔至少 14 天；新客偏基础器材或套装，复购偏加重哑铃和杠铃片。月初月末、周末略活跃，周内有自然波动。
- 使用现有商品、图片与规格，每笔固定运费 $7；金额由商品单价和数量计算。
- 每笔包含虚构姓名和邮箱、当地日期时间和配送状态；配送地址使用官网公开的真实健身房营业地址，详见 [地址来源](docs/admin-address-sources.md)。这些健身房与模拟订单、客户身份没有真实关联。
- 前后台共用订单号规则：`OM-时间编码-四位尾码`。历史订单号与各自下单时间对应，刷新不会改变。
- 时间按各订单美国当地时区展示，主要安排在午间和晚间；这是模拟分布，并非真实购物统计。
- 可搜索、按月份和状态筛选、排序、翻页，点击订单号打开详情；统计和周图表由订单计算，每页 15 条，共 28 页，采用省略号分页。
- 无真实登录鉴权、数据库或外部请求。数据在 `dist/admin-data.js`，与前台会话订单独立；公开托管时 `/admin.html` 也可直接访问。
